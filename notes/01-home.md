## Grid การ์ด (3.2d)

- 3 / 2 / 1 คอลัมน์ + pager (`/?page=`)
- `/media/...` route
- กดหน้าเดิม = reset ทุกอย่าง (`PageSlot`)
- เส้นแถวยาวเต็มแถวเสมอ (วาดจากการ์ดใบแรกของแถว) แม้แถวสุดท้ายไม่เต็ม
- เปลี่ยนหน้า: การ์ดออก 180ms → เข้า 220ms (stagger 34ms) → จุดลงจอด 450ms → เลื่อนกลับแถบกรองด้วย `glideTo` (เขียนเอง 640–1400ms ตามระยะ)
- ~~เคอร์เซอร์ VIEW~~ ไม่ทำ — v4 มีโค้ด `_viewDot` แต่ไม่ได้เรียกใช้ (เจ้าของยืนยัน 30 ก.ย. 69)

### Pager

- จุดไถลโค้งต่ำ 12px / 410ms (ท่า `"slide"` ตาม v4)
- ลูกศร SVG ข้าง PREV / NEXT เฉพาะมือถือ (v4 ไม่มี)

### จุดบนการ์ด (`CardDot.tsx`) — เมาส์

- จุด 8px หน้าหมวดของการ์ดที่ hover · หมวดเลื่อนหลบ 20px (.5s)
- ย้ายการ์ด = จุดวิ่งแบบสปริง v4 (.16/.64, ยืดตามทิศทาง) แล้วเด้งลงจอด
- ออกนอกการ์ดรอ 90ms (ข้ามช่องระหว่างการ์ด)
- ออกนอก grid / เปลี่ยนหน้า = หดหาย · กด = หด .7
- จุดอยู่นอก grid (ไม่ให้โดน nth-child / `[data-swap]`)
- กลับสีบนของดำ (ดู [shared.md](shared.md))

### จุดบนการ์ด — มือถือจริง (< 768 + `pointer: coarse`)

- ไม่มี hover → จุดตามการเลื่อน
  - การ์ดใบสุดท้ายที่ขอบบนเลยกลางจอ (`LINE` .5) · กันกระพริบ `HOLD` 8px
  - ยังไม่มีการ์ดเลยกลางจอ / grid เลื่อนพ้นจอด้านบน = ไม่มีจุด
  - เปลี่ยนการ์ด = สั่นเบาๆ เฉพาะ Android (`src/lib/buzz.ts`)
  - touch ยกนิ้ว (pointerout) ไม่ซ่อนจุด
- **การ์ดบนมือถือ (เจ้าของเลือก 30 ก.ย. 69, ต่างจาก v4)**
  - แถวแรก `● CATEGORY  tags` (ไม่มีวันที่ — แท็กยาวเคยดันวันที่ตกบรรทัดเป็น "30 JUN / 26")
  - เมื่อจุดมาถึง: `NO 004` (ชิดซ้าย) กับวันที่ (ชิดขวา) สไลด์ลงจากขอบล่างรูปเข้าไปในช่องว่าง 14px ใต้รูป ไม่จองที่
  - แถวหมวดขยับลง 6px (margin 14 → 20, 0.42s) · การ์ดสูงขึ้นแค่ 6px (284 → 290)
  - ลองแล้วไม่เอา: บรรทัดใต้หมวดที่จองที่ไว้ตลอด · บรรทัดเหนือหมวดที่เปิดออก 17px
- **ตำแหน่งจุด**
  - คิดจากกรอบที่วาด หัก translate ของหมวดและการ์ดออก (reveal / page swap ไม่ดึงจุดเพี้ยน)
  - ความสูงใน grid เปลี่ยน = จุดย้ายตามหมวด (เคยค้างที่ชื่อเรื่องการ์ดถัดไป เพราะแท็กยาวตกบรรทัดแล้วหดกลับหลังวัดตำแหน่ง)
- **แก้จุดสะดุดตอนเลื่อนขึ้น (30 ก.ย. 69)**
  - สาเหตุ: เลื่อนลง การ์ดใบบนหดหักล้างแถวหมวดที่ลง 6px พอดี · เลื่อนขึ้นไม่มีอะไรหักล้าง → จุดถูกดึงทีเดียว 5px กลางจังหวะเด้ง · offsetTop ปัดเป็นจำนวนเต็มด้วย
  - แก้: จุดตามแถวหมวดทุกเฟรมระหว่างที่แถวยังเลื่อนเข้าที่ (ขยับจุดกับเป้าไปพร้อมกัน สปริงไม่เปลี่ยน)
  - วัดใน Chrome headless: เฟรมกระตุกสุดตอนขึ้น 4.4–5.3px → 0.37px เท่ากับตอนลง

### หัวคอลัมน์กดเรียงได้ (แบบ 06B ของ v4)

- No / Title / Category / Date (Tags ไม่เรียง) · หน้าตาเหมือนข้อความเทาเดิม
- **กฎเดียวทุกหัว (30 ก.ย. 69)**
  - ยังไม่กด = ใหม่สุดก่อนเหมือน grid (030 บน) · ไม่มีหัวไหนดำ ไม่มีลูกศร
  - กดครั้งแรก = น้อยไปมาก (NO 001 / A–Z / วันที่เก่าก่อน) ลูกศร ↓
  - กดซ้ำ = กลับด้าน ลูกศร ↑
  - (เคยตั้งค่าเริ่มเป็น 001 ก่อน แล้วเจ้าของเห็นว่าอันล่าสุดต้องขึ้นก่อน)
- ลูกศรอันเดียว ลอยข้างขวาห่าง 5px ไม่ดันข้อความ (DATE ยังชิดขวาตรงวันที่)

- เปลี่ยนการเรียง = กลับหน้า 1 + โพสต์ออก/เข้าแบบสลับ GRID/LIST

- มีผลกับ list เท่านั้น — grid ใหม่สุดก่อนเสมอ
- < 768 ไม่มี sort: หัว Title เดียว สีเทา กดไม่ได้

### มือถือ (< 768)

- การ์ดติดขอบล่าง (sticky, 12px + safe-area) = รูป 220×110 + excerpt (serif 14px, blur swap)
- จุดอยู่ในขอบซ้าย
- **มือถือจริง** (`pointer: coarse`): เลือกแถวตามการเลื่อน
  - แถวที่อยู่สูงกว่าขอบบนการ์ด 1 แถวเต็ม (เว้นให้อ่าน) · `HOLD` 8px
  - excerpt สูงตามข้อความ 1–3 บรรทัด (ยืดหด 0.3s) แต่เส้นวัดคิดจากความสูงแบบ 1 บรรทัด (`CARD_MIN_H`) — ถ้าขยับตาม = สลับแถวกลับไปมา
  - แถวอื่นจาง .65 · เปลี่ยนแถว = สั่นเบาๆ เฉพาะ Android (iOS ไม่มีทางให้เว็บสั่น ลอง `<input switch>` แล้วไม่ได้)
  - ระยะแถวที่เลือก → การ์ด 2 แถว (`GAP_ROWS`)
  - สุดรายการ: แถวสุดท้าย · 12px (`REST`) · การ์ด · 14px · pager
  - 4 แถวสุดท้ายระยะเว้นค่อยๆ หดเหลือ 0 (`CLOSE_ROWS`) ทุกแถวถึงถูกเลือกได้
  - คำนวณจาก offset (reveal เลื่อนแถว 22px)
- **คอมหน้าต่างแคบ:** การ์ดที่เดิม แต่ตาม hover (ไม่ hover = ซ่อน)
- ≥ 768 ใช้แผงข้างชื่อตาม v4
